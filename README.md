# Miami Graphics

Лаунчер графических модификаций GTA V и студия оружейных скинов.

[English](README.en.md) · [Техническая документация](https://hntenjoyer.github.io/miami-graphics/)

Windows · .NET 8 · WPF + WebView2 + React

---

## Что это

Десктопное приложение, которое ставит графические моды в GTA V без ручного возни с архивами.
Пользователь выбирает мод в каталоге, лаунчер сам находит игру, снимает резервную копию чистого
`update.rpf`, вычисляет разницу и вносит её в архивы игры. Плюс к этому — редакторы, которые
делают контент прямо на месте: 3D-студия оружейных скинов, конструктор прицелов, редактор миникарты,
студия трассеров, диагностика ПК.

Работа идёт на уровне RPF-архивов игры: разбор, пересборка, NG-шифрование, контроль контрольных сумм
и бюджета стриминга. Ошибка на этом уровне роняет игру, поэтому почти всё в коде — про проверки.

## Сборка

```bash
dotnet build MiamiGraphics.Core.sln -c Release
```

В solution входят семь проектов: Core, Bridge, Shell, Core.Tests, RageLib, RageLib.GTA5,
CodeWalker.Core. Installer, Gunpack, DlcLab, RpfShrink и `Tools/*` собираются отдельно.

```bash
cd MiamiGraphics.Shell/ui && npm ci && npm run build
```

Нужно: .NET SDK 8+, Node.js 20+, Windows 10/11 x64.

Тесты:

```bash
dotnet test MiamiGraphics.Core.Tests/MiamiGraphics.Core.Tests.csproj
```

### Чего нет в репозитории

Часть данных не выкладывается и подтягивается в рантайме или кладётся руками:

| Что | Где ожидается | Как получить |
|---|---|---|
| Ключи шифрования GTA V (`gtav_ng_key.dat`, AES, NG-таблицы) | `MiamiGraphics.Shell/Keys/`, `additionals/keys/` | Скачиваются приложением в составе `additionals.zip` |
| `ArchiveFix.exe`, `swfmill`, JRE | `additionals/` | Там же, в рантайме, с проверкой SHA-256 |
| Серверная часть, миграции БД, конфиги инфраструктуры | — | В публичный репозиторий не входит |

Путь к ключам переопределяется свойством MSBuild `MiamiKeysDir` (Shell) и `MiamiKitDir` (RpfShrink).

## Работа с архивами игры

**Инъекция патча (Smart Rebuild).** Применяет `manifest.json` с действиями Replace / Add / Delete:
пересобирает каждый затронутый корневой RPF с откатом через `.bak`, создаёт недостающие вложенные
rpf из импортов, затем перепроверяет записи по обычным путям и дописывает то, что пересборка
потеряла. На `update.rpf` дополнительно вычищает осиротевшие объявления из `content.xml`.
→ `MiamiGraphics.Core/Injector/RpfInjectEngine.cs`

**Ворота бюджета стриминга.** Проверка на путях записи в архив (9 точек вызова в оболочке). Отклоняет
записи, чьё содержимое противоречит имени (магия `RSC7` / `RPF7`), считает память ресурса по
`SystemFlags` / `GraphicsFlags` и отказывает выше 90 МБ при потолке клиента 100 МБ — но сперва
пытается уложиться пережатием или уполовиниванием текстур.
→ `MiamiGraphics.Core/Services/RpfEntryGate.cs`

**Пересборка, подпись и снятие обфускации.** `ArchiveFix.exe` шифрует OPEN-пакет в NG и
пересчитывает хеши TOC и контрольную сумму заголовка — обязательно под финальным именем файла,
потому что NG-ключ выводится из имени. `RpfEncryptionCheck` открывает архив ровно так же, как игра.
`NgContainer` разворачивает паки со взведённым старшим битом `namesLength`.

**Редактирование на месте.** Замена, извлечение и перечисление файлов внутри живого `update.rpf` и
его вложенных архивов без полной пересборки — по пути, по имени или по сигнатуре содержимого.
Контрольные суммы чинятся от потомка к родителю.

**Рекурсивный диф.** Обходит два дерева RPF параллельно, спускается во вложенные архивы,
NG-расшифровывает и распаковывает каждую запись до настоящих байт перед сравнением по SHA-256.
Выдаёт действия Import / Replace / Delete.

**Компактор `rpfshrink`.** Пересобирает RPF7, убирая дыры от правок на месте, жмёт записи DEFLATE,
спускается во вложенные архивы до глубины 8, гоняет ArchiveFix от потомка к родителю и сверяет
каждую запись побайтно.

## Установка модов

**Каталог редаксов.** Сетка с поиском, сортировкой, избранным в облаке; страница мода со скриншотами
и видео, установка с отменой, умное удаление, отзывы 1–5 звёзд с распределением оценок.

**Разбор редакса.** Дифф чистого `update.rpf` против модифицированного пишет рабочую папку с
`manifest.json`, `content_info.json`, `component_map.json`, извлечёнными `patch_files/` и папками
компонентов. Это и есть фаза «Считаем ваши изменения» при установке.

**Кросс-инъекция.** Собирает новый патч из базового редакса плюс покомпонентные вставки из других
разобранных. Файлы `timecycle_mods_*.xml` сливаются на уровне модификаторов — набор имён и порядок
берутся из базового файла, переносятся только значения донора: подмена файла целиком рассинхронизирует
таблицу модификаторов игры.

**Определение компонентов.** Находит заменяемые части — `minimap.gfx`, `hud_reticle.gfx`, трассеры
ptfx, `bloodfx.dat`, таймциклы, арену и броню (по моделям-маркерам вроде `task_011_u.ydd`) — по
`filesToEnable` из `content.xml`, сверяя 8 ванильных RPF против пользовательских.

**Улучшения.** Ставятся набором: досеивает контейнеры слотов, которых нет в ванили, пересобирает общий
вложенный слот из чистой базы плюс файлы каждого улучшения, генерирует регистрацию
`content.xml` / `setup2.xml` с `subPackCount` в `dlc_patch`.

**Оверлеи «Другое».** Самодостаточные rpf в корне `update.rpf`, каждый регистрируется элементом
`RPF_FILE` в `dataFiles` плюс записью в `filesToEnable` загрузочного changeSet: залазы, зелёные зоны,
удаление рюкзака, логотипы машин, быстрый заход. Идемпотентно; чужие копии находятся и вычищаются.

**Проверка на палево.** Сравнивает установленные файлы с чистыми оригиналами и оценивает каждую
находку как Neutral / Visual / Warning / Danger, включая пополевой дифф оружейных `.meta`
(чистое значение, значение мода, дельта в процентах) для владельцев вида `WEAPON_` / `COMPONENT_`.
Итог — вердикт Safe / Mixed / Danger.

### 3D-студия скинов

Редактор на three.js, встроенный в лаунчер через WebView2 и виртуальный хост — локальный веб-сервер
не поднимается. Ресурсы ствола достаются по HTTP Range из `pack.zip` с кешем по SHA.

| Инструмент | Параметры |
|---|---|
| Кисть | обычная / мягкая / спрей / маркер, 2–250 px, сила 5–100% |
| Ластик | возвращает исходные тексели |
| Заливка | допуск 1–120 |
| Альфа | пробивает дырки насквозь |
| Текст | 6 шрифтов, кегль 24–800, обводка 0–60 px |
| Фигуры | линия, прямоугольник, круг, треугольник — редактируются после постановки |
| Наклейки | 5 встроенных штампов 256×256 либо своя картинка |

Мазки обрезаются по UV-острову под курсором маской до 2048 px по стороне. Слои двигаются,
переупорядочиваются и удаляются; HUD трансформации даёт размер 10–600%, поворот ±180°, прозрачность 5–100%.

**Проекция фото на модель.** Проецирует картинку вдоль осей камеры, растеризуя каждый треугольник в
пространстве текстуры с билинейной выборкой, затуханием края 4% и отсечением задних граней —
получается один бесшовный слой на каждую задетую текстуру.

**Тонированное стекло.** Помечает текстуры как стекло (цвет плюс непрозрачность 10–92%). На установке
шейдер переводится из render bucket 0 в `normal_spec_alpha.sps` (хеш 2021887493, bucket 1, маска
0xFF02), в диффуз запекается равномерная альфа с зажимом 8..255.

**Навесное 3D.** Плоская пластина, вырезанная из картинки (2–40 см, глубина 5–45%), либо импортированный
`.glb`, слитый в одну геометрию (масштаб 10–400%, рыскание ±180°, потолок 65 000 вершин). Вшивается
прямо в drawable ствола объявлением GTAV1 (шаг 44) с привязкой к `Gun_Main_Bone` и пересобранным
`BoundsData`.

**PNG в объём.** Силуэт по альфе (порог 64) → уменьшение до 72 px → обход контура по Муру →
упрощение Рамера — Дугласа — Пекера (epsilon 1.15) → триангуляция отсечением ушей → передняя и задняя
грани плюс боковые стенки с жёсткими нормалями.

**Анимированная деталь.** Отдельный компонент: `.ydr` со скелетом на 2 кости (базовая + подвижная,
тег 417) на шейдере `default.sps` с параметрами `globalAnimUV0/1`, зацикленный `.ycd` (дорожки UV-скролла 17/18 либо
качание/вращение кости, дорожка 1) на 30 fps с зажимом 8–600 кадров, архетип `.ytyp` (флаги 0x80600)
и `.meta` компонента. Скорость скролла 0.5–4, период 0.5–8 с, поворот XYZ ±180°, смещение XYZ ±20 см,
зеркалирование. Поддержано 10 стволов.

**Публикация.** 5 слотов на аккаунт, имя до 48 символов, описание до 240. Недельные лимиты: 2 попытки
на конкретный ствол, 4 работы на базе пака, 2 своих пака, максимум 3 ствола в своём паке — проверяются
в клиенте по `WorkshopFlowLimits` и подтверждаются на сервере.

## Редакторы

**Миникарта.** Перекрашивает каждую копию `minimap.gfx` в живом архиве и применяет твики на реальной
сцене gfx: холст 191×136, окно радара по X 6–185, по Y 8–122. Цифры HP и брони, раскладка полос,
позиции из `frontend.xml`, вклеенные кольца дальности, пакеты большой карты.

**Прицел.** Размер точки, зазор, длина, толщина, наклон, обводка — раздельно по группам оружия
(все / пистолеты / ПП / винтовки / дробовики), непрозрачность, масштаб 50–200%. 1 игровой пиксель =
20 твипов. Обмен по кодам KNK, которые протухают через 30 дней без использования.

**Трассеры и дым.** Назначает каналы трассеров по стволам и настраивает каждый канал (градиент в три
точки, толщина, длина, цвет дыма) поверх кешированного базового `core.ypt` — всё уходит одним
манифестом и одной пересборкой `update.rpf`. Отдельно меняются две ptfx-текстуры дыма и обнуляется
`TracerFx` по `update.rpf` и `dlcpacks`.

**Настройки графики GTA.** Две вкладки над `settings.xml`: конструктор по опциям из серверного каталога
оптимизаций, где наведение на карточку показывает значение на весь экран, а клик перебирает варианты
(пустое значение = «своё значение»), и публичные PRO-пресеты, которые заполняют конструктор, а не
пишут файл напрямую.

## Диагностика ПК

Снимок железа собирают 26 независимо обёрнутых сборщиков, которые только читают WMI, реестр и
`powercfg`; упавший сборщик попадает в `CollectorErrors`, а не роняет отчёт.

- **Слоты памяти из сырого SMBIOS.** Разбор структур type 17 даёт все слоты, включая пустые, с именами
  в стиле платы (A2, B2) и паспортной против фактической частоты MT/s — `Win32_PhysicalMemory` этого не даёт.
- **Мониторы с настоящими именами.** EDID-имя из `WmiMonitorID` с откатом на дескриптор 0xFC в реестре,
  видеокарта, разрешение, текущая и максимальная частота на этом же разрешении.
- **Тиры железа под GTA RP.** Процессор — S..D по разбору названия, с пометкой X3D, гибридных P+E и
  ноутбучных версий (H/HS/HX на тир ниже, U на два). Память — по числу каналов, объёму и состоянию
  XMP/EXPO. Диск — тот, на котором лежит игра (NVMe = S, SATA SSD = A, USB = B, HDD = D).
- **Движок находок.** До 49 разных находок со стабильными идентификаторами (`ram-xmp-off`,
  `game-on-hdd`) и вилкой выигрыша, где она известна: XMP выключен — 10–25%, одноканал — 10–30%.
  Отдаются только идентификаторы и числа, текст локализует интерфейс.
- **Применение в один клик с журналом отката.** 31 твик; перед каждым изменением прошлое состояние
  пишется в `journal.json`, перед первым создаётся точка восстановления Windows.
- **16 проактивных твиков** — профиль MMCSS Games, `SystemResponsiveness` 10, ускорение мыши,
  `Win32PrioritySeparation`, `NetworkThrottlingIndex`, HAGS, исключения для `GTA5.exe`.
- **Профиль NVIDIA через NVAPI.** Прямые вызовы `nvapi64.dll` DRS без сторонних утилит:
  `PREFERRED_PSTATE` = prefer max, `PRERENDERLIMIT` = 1, кеш шейдеров 10 ГБ.
- **Безопасность по античиту.** Отказывается выключать то, что админы RP-серверов читают как скрытые
  следы — Prefetch и службу EventLog — и наоборот, чинит их, если это сделал другой «оптимизатор».
- **Чистка плацебо.** Находит и убирает из `commandline.txt` флаги из чужих гайдов, которых в игре нет:
  `-high`, `-norestrictions`, `-nomemrestrict`, `-veryhigh`.

## Hot-swap для Rockstar-режима

Замораживает модифицированные `update\update.rpf` и `dlcpacks\patchday18ng\dlc.rpf` в образ вне папки
игры, подставляет моды на старте игры и возвращает чистые файлы на выходе.

Пять методов разложены по трём осям: агент против ручного триггера, образ на томе игры против выбранной
папки, атомарный `File.Replace` против копирования с переименованием. Одна таблица задаёт шаг опроса
(250 / 500 / 1000 мс), дебаунс разоружения (3000 или 0 мс) и убивать ли процессы игры перед возвратом.

Агент — тот же exe, перезапущенный как `--hotswap-agent` из задачи ONLOGON. Пишет heartbeat раз в 10 с,
повторяет неудавшееся вооружение раз в 10 с и просыпается по подписке WMI `Win32_ProcessStartTrace`,
а не частым опросом. Каждой файловой операции предшествует запись в журнал одной из пяти фаз, так что
прерванная заморозка откатывает мод обратно в игру, а недоделанное вооружение возвращает чистый файл.

Отдельно отслеживается починка через Rockstar Games Launcher: раз в 5 с сверяются размер и метка
времени, вооружение блокируется, пока рядом лежат свежие (моложе 10 минут) `.part` / `.partial` /
`.download` / `.rgl_tmp`.

## Сеть и доставка

**Параллельная докачка.** Многопоточный HTTP Range с позиционной записью без блокировок: один поток
ниже 8 МБ, выше — до 8 (потолок по узлу: ru2 — 2, spb1/spb2/msk/hnt/eu/ru — 4,
остальные 8), буферы 512 КБ, сторожевой таймер простоя 30 с,
повтор на меньшей параллельности при 503 и карта возобновления блоками по 8 МБ — смена зеркала не
начинает файл заново.

**Обход DPI.** Режет TLS ClientHello на 3 сброшенных фрагмента, чтобы DPI не прочитал SNI; прав
администратора не нужно. Опционально DNS-over-HTTPS (Cloudflare / Quad9 /
NextDNS) против подмены DNS. Применяется ко всем `HttpClient` лаунчера и к нативным запросам WebView2.

**Сетевой доктор.** Проверяет хранилище региона и каждый узел по горячему пути, холодному пути
(смещение 0 и диапазон в середине файла) и числу принятых соединений — чтобы сказать, что именно
сломалось. Запускается из настроек и автоматически при скорости ниже 10 МБ/мин.

**Проверенная загрузка.** Единственная точка отказа по SHA-256 для всего, что лаунчер кладёт в игру:
нет эталонного хеша — отказ; эталон никогда не берётся из самого архива; байты пишутся в `.part` и
переименовываются только после проверки; хеширование потоковое кусками по 4 МБ.

**Дельта-обновление.** Скачивает только файлы с изменившимся SHA-256 — единицы мегабайт вместо полной
полезной нагрузки. Любой сбой откатывается на полный установщик.

**Защита установки.** Мьютекс единственного писателя над `update.rpf` с таймаутом 10 минут, преднроверка
места на диске с резервом 2 ГБ под систему, поиск через Restart Manager процесса, держащего файл, и
восстановление осиротевших `.rpf.bak` при старте.

## Аккаунты и каталог

Вход по почте или нику через RPC `authenticate_user`, дальше сессионный токен. Двухшаговая регистрация,
сброс и смена пароля, смена почты, правка профиля — каждое действие подтверждается шестизначным кодом
на почту. Закрытая бета: код привязывается к вычисленному HWID, при любой сетевой ошибке доступ
считается закрытым.

Каталоги: редаксы и их версии по слотам, ганпаки со стволами и вариантами, пресеты настроек, библиотека
брони, большие карты, группы оптимизаций (кеш 5 минут), три избранных слота на главной. Отзывы — один
на пару (объект, пользователь) с перезаписью. Витрина авторов с подпиской и лентой. Сборки игроков:
редакс + ганпак + постволовые замены + броня + профиль настроек, модерация submit → pending →
approve / reject → resubmit.

Коды HNT-XXXX-XXXX выгружают состояние установки одним снимком и проигрывают его на другой машине.
Алфавит кода не содержит I, O, 0 и 1.

Мост WebView2 маршрутизирует **393 именованные команды** между React и C# конвертами
request / response плюс проталкиваемыми событиями прогресса; сообщения с чужих origin игнорируются,
78 изменяющих команд помечены критическими.

## Интерфейс

React + TypeScript, живёт внутри WebView2. Локализация в трёх языках (ru, en, pl): интерфейс стартует на русском
и откатывается на английский, движок откатывается на русский. Файл `de.json` в репозитории есть, но
ни React, ни `Loc.cs` его не подключают. Студия скинов несёт свой словарь на чистом JS — там четыре
языка с русским как запасным и правилами множественного числа отдельно для славянских и германских.

Экраны: онбординг и первый запуск, резервная копия чистой GTA (7 шагов над 9 фазами бэкенда с живой
скоростью и ETA), каталог редаксов, кастомизация компонентов, ганпаки, мастерская, единичные компоненты,
«Другое», настройки графики, диагностика ПК, проверка на палево, сборки игроков, загрузки и
установленное, настройки приложения.
